# 暗闇FPS（VRChat）ブレインストーミングのメモ（途中）

まだ設計書ではありません。会話で決まったことと未決のことのメモです。手元の PC の Claude Code で続きから進めるために残しています。

## 決まったこと（ユーザーの回答）
- VRChat 用の対戦FPS。**友達 4〜8 人**で遊ぶ想定。
- **本当に真っ暗**で、**かなり近くに行かないと相手が分からない**（提案：2〜3m でうっすら輪郭が見える程度）。
- **音を頼りに**相手を探す。
- 銃は**頭なら 1 発、胴体なら 2 発**で倒れる。
- ボイスチャットは**そのまま**。しゃべると方向と距離で相手に居場所がばれる。
- **マップは複数**。マップごとに違いをつけたい。

## Claude の提案（ユーザーが明確には承認していない）
- 足音は自分で作る（VRChat はアバターの足音を鳴らさない）。走るとうるさく、ゆっくり歩くと静か。
- 撃つと銃口の火と銃声で、撃った人の居場所がばれる。
- 試合の形：個人戦、やられたら終わり、1 ラウンド 2〜3 分、最後の 1 人が勝ち（ユーザーから異論はないが、明確な選択もまだ）。
- マップの最初の案（**ユーザーが何か言いかけた途中**。「それなんだけど」のあと、作業を手元の PC に移す話になった）：
  - 古い洋館（狭い屋内。床板のきしみ、ドアの音）
  - 地下水路（迷路。水たまりの音、反響）
  - 夜の森（広い屋外。落ち葉、風の音で聞き取りにくい）
  - マップはラウンドごとに順番に回すか、投票で選ぶ

## リポジトリから分かったこと
- このリポジトリは荒野ホースレースのワールド（UdonSharp、`HorseRace/Build World` で自動生成）。FPS は別ワールドとして横に作る想定（未確認）。
- `Assets/HorseRace/Scripts/Revolver/RevolverHolder.cs`：VR とデスクトップの構え、撃つ操作、構えの同期、銃口の火と銃声が実装済み。流用できる。
- VRChat のプレイヤーには当たり判定がない。頭と胴の判定は、ボーン位置（GetBonePosition）に自分たちで判定を置いて作る。
