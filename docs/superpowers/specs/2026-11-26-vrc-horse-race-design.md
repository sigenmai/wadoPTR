# 荒野横断ホースレース（仮題）設計書

日付: 2026-11-26
対象: VRChat ワールド（VRChat SDK3 Worlds + UdonSharp / Unity）

## 1. 何を作るか・なぜ作るか

馬に乗って荒野と砂漠を駆け抜け、**能力で互いを妨害し合う** VRChat 用マルチプレイのレースワールド。
『ジョジョの奇妙な冒険 第7部』の「大陸横断レース × 特殊能力 × 遺物の奪い合い」というワクワク感に刺激を受けているが、
**作品名・キャラクター・スタンド名・デザイン・セリフ等は一切使わない完全オリジナル**として作る。

最優先は **馬の操作感**。妨害バトルがあっても、乗っていて気持ちいいことが土台。

## 2. ゴール / 非ゴール / アンチゴール

### ゴール
- VR・デスクトップ両方のプレイヤーが同じ条件で遊べる
- 1回のプレイ：**3ステージ × 約5分 = 約15分**、**最大8人**
- 固定能力（レース前に1つ選択）＋ コース上の **遺物** で能力が強化される
- 高低差のある地形（峡谷・崖・砂丘）を走ること自体が楽しい
- トゥーン調のビジュアル

### 非ゴール（今回はやらない）
- 原作の名前・キャラ・能力・見た目の再現
- セーブ / ランキングの永続化
- NPC（AI）ライダー
- 能力7種を超える拡張、アバターのカスタマイズ

### アンチゴール（動いても失敗とみなすもの）
- VR で酔う（急なカメラ回転・揺れ・強制的な視点移動）
- 他プレイヤーの馬がガクガク・ワープして見える
- VR とデスクトップのどちらかが明確に有利
- 妨害が強すぎて操作の上手さが意味をなさない

## 3. 制約
- VRChat SDK3 Worlds + UdonSharp。Udon の制約（同期変数の帯域、Udon の実行速度）に収める
- 組み立て・動作確認はユーザーの PC（Unity + VRChat クライアント）で行う。Claude はスクリプトと設計・手順書を書く
- **対応プラットフォームは PC のみ**（PC VR ＋ デスクトップ）。Quest/Android 対応はしない
- ワールドが重くなりすぎないこと（トゥーン調を選んだ理由の一つ）
- **地形・コースも Claude が作る**。Claude はこの環境で Unity を実行できないため、Unity エディタ拡張（メニュー1つでシーンを組み上げるツール）として納品する：
  - 地形生成ツール：ステージごとのパラメータ（峡谷・崖・砂丘・メサ）から Terrain の高さとテクスチャを手続き的に生成
  - コース生成ツール：コースの道筋（スプラインの点列）を定義データとして持ち、チェックポイント・遺物スポーン・スタート/ゴール・コース外リセット領域を自動配置
  - シーン組み立てツール：上記＋ロビー・レース管理・馬プレハブをまとめて配置
- ユーザーの作業は「プロジェクト準備 → メニュー実行 → VRChat でテスト → 感想を伝える」までに絞る。手順書はクリック単位で書く

## 4. 検討したアプローチ

| 案 | 内容 | 判断 |
|---|---|---|
| **A. 自前の馬コントローラー** | プレイヤーは VRCStation で馬に座る。移動はスクリプトで計算（レイキャストで接地・坂沿い、加速・旋回・ジャンプを自前実装）。各自の馬はオーナーがローカルで動かし、位置を同期して他者側で補間 | **採用**。操作感を完全に握れる唯一の方法。VR/デスクトップで挙動を共通化しやすい |
| B. Rigidbody 物理 | 物理演算で馬を動かす | 不採用。挙動がブレやすく調整しにくい、同期でガタつきやすい |
| C. アバター歩行＋見た目だけ馬 | 移動速度を上げるだけ | 不採用。乗っている感覚がなく、操作感重視に反する |

ユーザーが **A** を選択。

## 5. 決まっている設計

### 5.1 馬の操作
挙動（速度・加速・旋回・ジャンプ・スタミナ）は**全プレイヤー共通**。入力だけが違う。

| 操作 | デスクトップ | VR |
|---|---|---|
| 前進 / 減速 | W / S（またはスティック） | 左スティック前後（補助）＋ 手綱を引くと減速 |
| 旋回 | A / D | 手綱の左右どちらかを引く（スティックでも可） |
| 疾走（スタミナ消費） | Shift | 両手で手綱を振る（または指定ボタン） |
| ジャンプ | Space | ボタン |
| 能力発動 | E（照準は視線方向） | トリガー（照準は手の向き） |

- 速度段階：常歩 → 速歩 → 駆歩 → 疾走（スタミナ消費、尽きると一時的に駆歩上限）
- 坂：上りで減速・下りで加速。急な崖は落下、着地時に硬直（高さに応じて）
- **酔い対策（必須）**：カメラは馬の上下動・ピッチをそのまま伝えず平滑化。旋回は滑らか。被弾時に視点を強制回転させない

### 5.2 能力（7種、すべてオリジナル）
各能力は **Lv1〜3**。遺物を拾うとLvが上がる（ステージ開始時にLv1へリセット）。

| 能力 | 効果 | 強化で変わるもの |
|---|---|---|
| **砂塵（すなけむり）** | 自分の後方に砂煙を残す。中を通った相手は視界がかすみ、少し減速 | 範囲・持続時間 |
| **投げ縄** | 前方の相手に縄を掛け、自分は引き寄せられて加速、相手は一瞬減速 | 射程・引き寄せ力 |
| **岩壁** | 前方の地面から岩壁をせり上げる（コース妨害） | 壁の幅・枚数 |
| **蜃気楼** | 自分の分身を出し、一定時間半透明化して投げ縄などの対象にならない | 分身数・持続時間 |
| **鉄球** | 鉄球を投げる。地形でバウンドし、当たった相手はよろけて減速。投げ方（照準の傾き）で左右にカーブ | 弾数・カーブ量・よろけ時間 |
| **恐竜** | 一定時間、自分の乗騎が小型の恐竜に変わる。悪路・急坂で減速しにくく、体当たりで相手を弾き飛ばす。効果中は能力ボタンで咆哮（近くの相手の馬が怯んで減速） | 持続時間・体当たりの強さ |
| **爆弾** | 地面に爆弾を設置（数秒後 or 相手が近づくと爆発）。爆風で相手を跳ね上げ、着地まで操作不能 | 設置数・爆風範囲 |

- クールダウン制（目安 15〜25秒、調整対象）
- 原作の特定の技・演出（回転の技術、他者を恐竜化させる等）はなぞらず、上記の独自効果として作る
- **実装順（Claudeの判断）**：まず 砂塵・投げ縄・岩壁・鉄球 の4種で操作感と対戦バランスを固め、次に 恐竜・爆弾・蜃気楼 を追加する。7種の同時調整は負担が大きいため
- 当たり判定は**発動した側のクライアントで行い**、効果をネットワークイベントで全員へ送る

### 5.2b リボルバー（全員共通の武器）
- 全員が持つ、能力とは別枠の武器。レース中いつでも撃てる
- 弾数：1ステージ 6 発（ステージ開始で補充）
- 撃ち方：VR は手で構えてトリガー。デスクトップは右クリックで構え、左クリックで撃つ。構えている間は少し減速（×0.9）
- **外したとき**：自分の移動速度が 3 秒間 ×0.8（外し判定：弾が相手プレイヤーの当たり判定に当たらなかった）
- **当たったとき**：相手の馬がよろけ、1 秒間 ×0.6。視点は強制回転させない
- **同じ相手に 3 発当てる**と、その相手は遺物を 1 つ落とす（能力 Lv −1、Lv1 なら落とさない）。落ちた遺物は地面に出て誰でも拾える。3 発のカウントはステージごとにリセット
- 当たり判定は撃った側のクライアントで行い、結果をネットワークイベントで送る（能力と同じ方式）
- 見た目：Revolver.fbx（シリンダー・撃鉄・引き金が別部品。撃つと撃鉄が起きてシリンダーが 60° 回る）

### 5.3 遺物
- 各ステージのコース上に数か所出現。拾うと能力Lv +1（最大3）
- 取り合いを生むため、一度拾われたらそのステージ中は消える

### 5.4 レース進行
- ロビー：能力選択 → 全員準備完了 or マスターが開始
- ステージ1 → 2 → 3（各約5分）。各ステージの順位でポイント付与、合計で総合優勝
- ステージ間は次ステージのスタート地点へテレポート
- **ステージ終了条件（Claudeの判断）**：1位がゴールしてから60秒、または開始から5分30秒の早いほうで終了。未完走者は通過チェックポイント数（同数なら次CPまでの距離）で順位を決め、完走者より下位としてポイントを付与
- **ステージの広さ（Claudeの判断）**：各ステージは約1km四方のTerrainに収め、曲がりくねったコース（約2.5km）で約5分になるよう速度を調整する。3ステージは同じワールド内で原点近くに並べ、浮動小数点の誤差による揺れを避ける
- **途中参加**：次のステージから参加可（総合ポイントは0から）
- **途中離脱**：その時点のポイントで集計から外す
- 進行管理（ステージ状態・順位・ポイント）はインスタンスマスターがオーナーとして保持し同期

### 5.5 舞台（トゥーン調）
- ステージ1：**荒野** — 峡谷、岩橋、崖下りのショートカット
- ステージ2：**砂漠** — 大きな砂丘のアップダウン、砂丘越えジャンプ
- ステージ3：**荒野＋砂漠の境目** — メサ（台地）を越えてゴールの町へ
- 地形は Unity Terrain、コースはチェックポイントで順位と逆走を判定

### 5.6 ロビー（待ち時間も楽しませる）
- 荒野の小さな宿場町の広場。ワールドに入ると最初にここ
- **受付パネル**：参加方法（馬／徒歩）・能力・馬の見た目を選んで「エントリー」。エントリー者の名前・能力一覧を表示。開始ボタンはマスターのみ
- **練習場**（広場の隣）：坂・ジャンプ台・崖下りを一通り置いた小さな周回コース、能力を試せるカカシ（静止／移動）。練習場内では能力を自由に切り替え可・クールダウン短め。練習用の馬はレース用8頭とは別に用意し、乗り降り自由
- **たまり場**：焚き火とベンチ、前回レースの順位表（ステージ別・総合）
- カウントダウン開始時、エントリー者は練習場にいても自動でスタート地点へ移動

### 5.7 観戦（レース中ロビーにいる人）
- たまり場に大型中継モニター。中継カメラは1台・控えめな解像度
- 自動切り替え：基本は先頭を追う／2頭が近接して競り合っていればそちら／能力が命中したら数秒その場面。1カットは最短5秒・最長15秒
- モニター横にリアルタイム順位表（名前・能力・順位・残り時間）
- モニター下のボタンで追いかける人を選べる（押した本人の画面だけ切り替わる）
- レース参加者には中継を見せない。ステージ間の結果画面で順位を表示

### 5.8 演出
- **カウントダウン**：スタートラインに横一列、空に大きく「3・2・1」、号砲と砂煙でスタート。カウント中は馬が足踏み
- **ゴール**：ゴールゲート通過で紙吹雪と着順表示（「1st!」等）。1位ゴール時は鐘で全員に通知
- **総合優勝**：ゴールの町の表彰台へ上位3人を移動、花火と順位発表。ロビーの順位表を更新

### 5.9 馬の見た目
- 受付で毛色（栗毛・黒・白・ぶち等 5〜6色）と鞍・飾りの色を選択。性能は全員同じ
- **骨の馬**：見た目の選択肢の1つ（全身が骨格の馬）。性能・アニメーションは普通の馬と同じ

### 5.9b 乗り物：ラクダ（性能が違う別の乗り物）
- エントリー時に「馬」「ラクダ」「徒歩」から選ぶ（徒歩は Phase 2）
- 「挙動は全員共通」の例外。馬との違い：
  | | 馬 | ラクダ |
  |---|---|---|
  | 最高速度（疾走） | 13 m/s | 11 m/s |
  | スタミナ | 基本 | 1.6倍（消費が 1/1.6） |
  | 砂地 | 減速（×0.85） | 減速しない |
  | 旋回・坂 | 基本 | 旋回速度 ×0.8、上り坂の減速 ×1.3 |
- 新ルール：地形に「砂地」の区分を設け（砂漠ステージの大部分・荒野ステージの一部）、馬は砂地で減速する
- 狙い：荒野は馬、砂漠はラクダが有利になり、乗り物選びが作戦になる
- 見た目はラクダ1種（毛色選択なし）。歩様はラクダらしく、中速は側対歩（同じ側の前後脚を同時に出す）

### 5.10 徒歩での参加（縛りプレイ）
- エントリー時に「馬」か「徒歩」を選ぶ
- 徒歩は馬より遅い（全力でも馬の駆歩未満）。徒歩専用の近道（崖のよじ登り、岩の隙間の細道、つり橋）を使える
- 能力は馬と同様に使える。順位・ポイントは馬と同じ枠で競う
- 基本は馬が有利。「上手い人が近道を使いこなせば馬にも勝てる」程度の強さに調整する

### 5.11 町の人・観客（NPC）
- ロビーの宿場町に住民、各ステージのスタート・ゴール・見どころの崖に少数の観客
- 歩く・手を振る・歓声程度の簡単な動きのみ。レースには関与しない。各場所数人に抑える

### 5.12 ボイス
- ワールド内の全員の声が距離に関係なく全員に聞こえる（Udon で全プレイヤーの音声到達距離を最大にする）。Phase 1 に含める

### 5.12b 背景専用の環境アセット
- **厩舎（Stable）は背景専用**。プレイヤーが近づけない場所（コース外・柵の向こう・町の外れ）に置き、周りを見えない壁（BoxCollider）で囲んで中に入れないようにする
- 近くで見られないので、屋根のテクスチャの粗さは許容する
- 同じ扱いにするもの：メサ（MesaRock / MesaRockB）など、遠景用の大きな岩山

### 5.13 フェーズ分け（Claudeの判断）
- **Phase 1**：馬とラクダの操作・同期、3ステージとレース進行、能力4種（砂塵・投げ縄・岩壁・鉄球）と遺物、ロビー（受付・練習場・たまり場）、観戦、演出、馬の見た目選択
- **Phase 2**：恐竜・爆弾・蜃気楼、徒歩での参加（馬のバランスが固まってから調整するため）、町の人・観客、3Dモデル差し替え、効果音・BGM

## 6. ビルダーに任せること
- 各数値（速度・加速・スタミナ・クールダウン・ポイント配分）の初期値と調整
- コースの具体的なレイアウト、チェックポイント配置、遺物の配置（生成ツールのパラメータとして調整可能にする）
- 使用する無料/有料アセットの選定（トゥーン調で統一すること）
- 同期方式の細部（送信頻度・補間方法）。ただし「他者の馬がガクつかない」ことは必須
- UI（順位・スタミナ・能力クールダウン表示）のデザイン
