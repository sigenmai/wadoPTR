# プレイテスト チェックリスト

Unity と VRChat クライアントで実際に確認する項目。自動テスト（`dotnet test` / `dotnet build tests/UdonCompileCheck`）では分からないものだけを書く。

## このチェックリストの使い方

1. 先に [SETUP.md](SETUP.md) の手順で「HorseRace/Build World」まで終わらせ、Validate の警告が 0 件であることを確かめる。
2. まず一番下の「最終チェック」（設計レビューで挙げた 5 つの重点項目）をやる。ここが壊れていたら他を見ても意味が薄い。
3. そのあと Task 6〜11 の各節の「確認項目」を上から順に。1 人でできるものは Build & Test（クライアント 1）、「2 クライアント」「マスター」と書いてあるものはクライアント 2 以上で。
4. 各節の「セットアップ」は参考情報（Build World が自動で行う）。手作業で組み立てる必要はない。
5. 失敗した項目は、Console のメッセージ（赤・黄の文面）と再現手順をそのまま Claude に送る。

## Task 6: 乗り物

### 事前準備（シーン構成）
> **Build World が自動で行います（手作業は不要）**。メニュー「HorseRace/Build World」を実行すると、以下の構成・設定・参照がすべて自動で作られます。この節は確認用の説明です（Task 11）。
- メニュー「HorseRace/Create Horse Materials」→「HorseRace/Build Mount Animator」を実行し、`Assets/HorseRace/Animations/Mount.controller` ができている
- 乗り物 1 頭の構成:
  - ルート: `MountController`、`VRCStation`（Player Mobility = Immobilize、Station Enter Player Location = SeatAnchor、Disable Station Exit はレース中（`raceActive`）に乗り手がいる間だけコードが true にする（レース中に Jump で降車させないため。ロビー・練習場では降りられる。初期値はどちらでも可））、`Rigidbody`（Is Kinematic）、体の Collider
  - 子 `SeatAnchor`（座席）
  - 子 `Visual`（`MountVisual`、Horse / Camel / SkeletonHorse のモデル。各 Animator に Mount.controller、毛色マテリアル 6 種を Bay, Chestnut, Black, Gray, Palomino, Dun の順に設定、息づかい AudioSource はループ）
  - 子 `ReinsVR`（`MountInputVR`、mount と seatAnchor を設定）
- `MountController` の Ground Mask に地形のレイヤー、Obstacle Mask に壁・建物のレイヤーを設定
- 砂地の範囲に Is Trigger の Collider ＋ `SandZone` を置く

### 確認項目
- [ ] Unity Console のエラーが 0（UdonSharp のコンパイルを含む）
- [ ] デスクトップで乗って走る・曲がる・跳ぶ（W/S で歩様を上げ下げ、A/D で旋回、Space でジャンプ）
- [ ] 疾走（Shift）でスタミナが減り、尽きると駆歩までしか出ない（息づかいが荒くなる・耳が伏せる）。休むと戻る
- [ ] 坂で速度が変わる（上りで遅く、下りで速く）
- [ ] 崖から落ちると着地で硬直する（高いほど長い、よろめくアニメ）
- [ ] 砂地で馬だけ遅くなる（ラクダは変わらない）
- [ ] ラクダは馬より曲がりにくく、上り坂に弱い。最高速も低い
- [ ] 骨の馬・毛色が他人からも同じに見える（2 クライアントで確認）
- [ ] VR の手綱操作：片手を引くとその側へ曲がる、両手を引くと減速、両手を振ると疾走、低スタミナで手が振動する
- [ ] レース中（カウントダウン〜ゴール）はジャンプ（Space / ボタン）で降車しない。ロビー・練習場・ステージの合間はジャンプで降りられる
- [ ] 何らかの理由で降車してもレース中はすぐ再着席する（保険）
- [ ] VR で手綱の左右差が 10cm 未満では曲がらない。スティックを倒している間はスティックが優先される
- [ ] ラクダは中速で側対歩、骨の馬も自分のクリップで動く（オーバーライドコントローラ）
- [ ] 低スタミナで耳が伏せる（Animator に上書きされない）
- [ ] 2 クライアントで相手の乗り物がガクつかない（送信側のサーバー時刻で 0.22 秒遅れを補間・最大 0.3 秒外挿）。駈歩・襲歩で並走しても、相手の馬と騎手が後ろへ戻ったり前へ飛んだりしない。テレポート（スタート位置・CP への戻し・囲い）はスナップする
- [ ] 座席のピッチ・上下動が平滑化されていて酔わない。被弾（ノックバック）で視点が勝手に回らない
- [ ] 速さ（2026-11-27 改定）：馬は常歩 4 / 速歩 8 / 駆歩 14 / 疾走 18 m/s、ラクダは 4 / 7.5 / 12 / 15 m/s。0→18 m/s が約 3.3 秒。18 m/s でも曲がれる（最高速で 50°/秒）、脚の動きが速さに合っていて足が滑って見えない。1 ステージ（2.5km）が約 3 分 20 秒〜3 分 30 秒（ラクダ約 4 分）
- [ ] 18 m/s・低フレームレートでも CP（奥行 6m）を素通りしない。正面の岩・壁をすり抜けない
- [ ] 騎乗ポーズ（`Station_Ride.controller`、Station の Animator Controller）：馬・ラクダ・骨の馬に**またがって**座る（脚が胴の両側、手が手綱の位置）。椅子に座る既定のポーズにならない。デスクトップと VR の両方、背の低い／高いアバター・アバターの大きさを変えた直後（数秒で測り直す）でも、お尻が鞍に乗っていて浮かない・めり込まない（他のクライアントからも同じ位置に見える）
- [ ] 鞍の微調整：座ると右前に真鍮色の文字の札「鞍の位置」が出る（自分にだけ見える。レースで走っている間は隠れる）。▲▼で高さ・前後 1cm、傾き 1°（VR は指先で触れて押し続けると連続、レーザー・クリックは 1 刻み）、「戻す」で 0。デスクトップは PageUp/PageDown＝高さ、Home/End＝前後、Insert/Delete＝傾き（押し続けで連続、レース中も効く）。値は馬・ラクダ・骨の馬で別々に、ワールドに入り直しても残る（VRChat Persistence）
- [ ] ロビーで台帳にサインすると、自分の乗り物（待機場所）に座って待つ（乗り物・毛色を変えてサインし直すとその乗り物に座り直す）。ロビーでは Jump で降りられ、自分の乗り物をクリック／Interact するとまた座れる（他人の乗り物は Interact できない）。座ったまま町を歩ける。練習場の杭に触れると自分の乗り物から降りて練習用の馬に乗り換わる。カウントダウンで必ずスタート位置の自分の乗り物に座る（ステージ間・CP への戻し・囲いへの移動でも座ったまま）

## Task 7: チェックポイント

### セットアップ
> **Build World が自動で行います（手作業は不要）**。メニュー「HorseRace/Build World」を実行すると、以下の構成・設定・参照がすべて自動で作られます。この節は確認用の説明です（Task 11）。
- 各 CP は Is Trigger の Collider を持つ GameObject に `Checkpoint` を付ける（Collider は乗り物の体より広く、コースを横切る形に）
- `index`（スタートライン通過 = 0、最初の CP = 1、以降 +1）・`stageIndex`・`isGoal`（最後の CP だけ true）・`next`（次の CP、ゴールは空）を設定
- 乗り物の体の Collider は Ground Mask に含めない（自分の体を地面と誤認しない）
- 連続する CP を結ぶ直線がコースから 60m 以内に収まるように CP を置く（コース外判定は直前の CP から次の CP への線分からの距離）
- CP の Transform の向き（Y 回転）がリセット後の向きになる。コース進行方向に向ける
- `MountController` の `Current Stage` はレース管理側が設定する（既定 0）。`ResetProgress` でステージ開始時に初期化する

### 確認項目
- [ ] 逆走しても CP 番号が進まず、順位が上がらない
- [ ] CP を飛ばして先の CP に入っても進まない（順番通りにだけ進む）
- [ ] 崖下・地形の下に落ちたら 3 秒以内に最後に通った CP へ戻る（地形の下に抜けたときはほぼ即時）
- [ ] コースから 60m 以上離れて 3 秒たつと最後の CP へ戻る。戻ったときは速度 0
- [ ] ゴール通過でゴール時刻（`syncFinishAt`）が記録され、2 回目の通過では上書きされない
- [ ] 他のプレイヤーが CP に触れても自分の進行は変わらない
- [ ] 深い谷（50m 超）を跳び越している間は、2 秒未満ならリセットされない。地面のない空間へ落ち続けたら 3 秒以内に戻る
- [ ] ゴール後はコース外へ惰性で行ってもリセットされない
- [ ] レース外（`raceActive` が false）・操作不能中は CP に触れても進まない

## Task 8: レース進行・ロビー

### セットアップ（シーンに置くもの・つなぐもの）
> **Build World が自動で行います（手作業は不要）**。メニュー「HorseRace/Build World」を実行すると、以下の構成・設定・参照がすべて自動で作られます。この節は確認用の説明です（Task 11）。
- **前提**: VRChat SDK 3.8 以降・UdonSharp 1.2 以降（引数つきネットワークイベント `[NetworkCallable]` を使う）。TextMeshPro を使用（日本語フォントの TMP Font Asset、台帳は手書き風、黒板はチョーク風を用意）
- **RaceManager**（空の GameObject 1 つ、Synchronization = Manual）
  - `Mounts` に MountController 8 頭（slot 0〜7 の順。各 MountController の `Slot Index` も同じ番号に）
  - `Start Points` に 24 個（index = ステージ × 8 + slot。Transform の Y 回転がスタート時の向き）
  - `First Checkpoints` に各ステージの CP（index 1）を 3 つ
  - `Finish Pens` に各ステージのゴール後の囲い（柵で囲った広場）の中心を 3 つ
  - `Mount Parking`（任意）に 8 か所、`Lobby Spawn` にロビーの戻り位置
  - `Starter`（任意、Task 10）／`Stage Reset Targets`（Task 9 の能力・遺物："ResetForStage" を受ける）／`Refill Targets`（Task 9 のリボルバー："Refill" を受ける）
  - `Ledgers`・`Rank Boards`・`Poster Cards`・`Mount Pickers`・`Start Bell`・`Practice Area` を下記のオブジェクトにつなぐ
- **手配書の壁**: カード 6 枚に `PosterCard`（Collider 付き）。kind 0 = 乗り物（value 0 馬／1 ラクダ）、kind 1 = 能力（value 0 砂塵／1 投げ縄／2 岩壁／3 鉄球）。`Poster Visual` に紙、`Taken Visual` にピンだけ残った跡（任意）、`Label` に文字（任意）
- **柵の馬**: 7 頭（毛色 0〜5＋骨の馬 6）に `MountPicker`（Collider 付き、`Coat`、`Visual` に MountVisual、`Chosen Marker` に鞍・リボンなど）。レース用 8 頭とは別の見た目だけの馬
- **受付カウンターの台帳**: `EntryLedger`（Collider 付き）、`Page Text` に台帳ページの TextMeshPro、`Sign Sound`（任意）
- **スタート台の号砲**（クラス名は `StartBell` のまま）: 机（FarmProps_05）に置いた拳銃（Packs/Revolver）と見えない球の Collider。`Ring Sound`（空砲、2D 推奨）・`Tap Sound`（乾いたカチッ）・`Note Text`（紙の札）・`Hammer` / `Cylinder`（拳銃の部品）・`Smoke`（銃口の煙）
- **練習場**: 練習場全体を覆う Is Trigger の Collider ＋ `PracticeArea`（`Release Radius` は練習場の外周より少し大きく）。練習用の馬 2 頭（レース用とは別の MountController 一式）をつなぐ杭それぞれに `PracticeHorsePost`（Collider 付き、`Mount`・`Home`・`Coat`・`Race Manager`）を置き、`PracticeArea.Posts` に登録。カカシは Task 9
- **黒板**: 各 CP の黒板に `RankBoard`（`Board Text` は TextMeshPro）。たまり場の黒板は `Show Last Race` を ON にする（ロビー中は前回のレースの表＝ステージ別の着順と総合ポイント）
- **文字の型**: ワールド内の文字はすべて TextMeshPro（3D）。素材ごとの見た目は Generated/Fonts/TMP_Ink・TMP_Chalk・TMP_Sign・TMP_Brass（Build World が作る SDF マテリアルのプリセット）。uGUI の Canvas は使わない
- **懐中時計**: 常に有効な空の GameObject に `PocketWatch`、見た目はその子の `Watch Root`（紙の文字盤に TMP の数字 12 個と「│」の針 2 本）。`Face Text` に「残り 3:12」、`Tick Audio`（任意、残り 10 秒の時計の音）
- **首の札（補助表示）**: ロビーのレバー（Collider 付き）に `MinimalHud`。`Hud Root` はレバーの子にしない別オブジェクト（手配書の紙 0.20 × 0.13m）に `Header Text`・`Rank Text`・`Time Text`・`Progress Text`（TMP 3D）と持久力の印 `Stamina Pips`（宝石 5 つ）。`RaceManager.hud` にこの MinimalHud。`Cp Tick`・`Finish Audio`・`Whoosh` は 2D の AudioSource（任意）

- [ ] 最終ステージ中にサインしても「次のステージから」には載らない（台帳に「次のレースはロビーで」）
- [ ] マスター退出でも続行（新マスターでタイマー・順位・ポイントがそのまま続く）
- [ ] 抜けた人の枠が消える（台帳・黒板から消え、その乗り物は空になり、1 秒ほどで乗り物の置き場へ戻る）
- [ ] ワールドの端同士（ロビーとステージ 3 のゴールなど）でも声が普通に聞こえる。後から入った人の声も聞こえる
- [ ] 首の札（手配書の紙：見出し「第1幕 荒野」（ステージの色）・大きな「3位」・「残り 3:12」・「■■■□□□ ゴール」・持久力の宝石 5 つ）がレース中だけ出る。VR は自分の馬の鞍の前・たてがみの上に乗り手へ 35° 起こして置かれ（顔に付いてこない。全速でも札が遅れない）、デスクトップは視界の左下の隅に小さく（×0.55、画面の約 11° × 7.5°、持久力の宝石まで画面の中。向きだけ 0.15 秒遅れて追う）。レバーで消せる・戻せる（自分だけ、札「札：出す／しまう」）

- [ ] たまり場の黒板に、ロビーに戻った後も前回のレースの表（ステージ別の着順・合計点）が残る。途中で抜けた人は載らない。新しいレースの総合結果で更新される

## Task 9: 能力・遺物・リボルバー

### セットアップ（シーンに置くもの・つなぐもの）
> **Build World が自動で行います（手作業は不要）**。メニュー「HorseRace/Build World」を実行すると、以下の構成・設定・参照がすべて自動で作られます。この節は確認用の説明です（Task 11）。
- **前提**: Task 8 と同じ（VRChat SDK 3.8 以降・UdonSharp 1.2 以降、引数つきネットワークイベント `[NetworkCallable]` を使う）
- **レイヤー**（例）: `HR_Target`（乗り物の体と騎手の当たり判定）、`HR_Wall`（岩壁）。地形・岩は既存の地面レイヤー
  - 各乗り物の体の Collider を `HR_Target` に置き、騎手の上半身を覆うカプセル Collider（Is Trigger 可）を乗り物の子として追加して `HR_Target` に置く
  - `HR_Target` と `HR_Wall` は MountController の `Ground Mask` に含めない。`HR_Wall` は `Obstacle Mask` に含める
- **AbilityCaster**: 乗り物（レース用 8 頭＋練習用 2 頭）の MountController と**同じ GameObject** に 1 つずつ（同期は Manual のまま）
  - `Mount` = 同じ MountController、`Caster Id` = レース用は slot 番号 0〜7、練習用は 8・9（全部で重複させない）
  - 練習用の 2 頭だけ `Practice Mount` を ON、`Practice Area` を設定。全頭 `Race Manager` を設定
  - `Target Mask` = `HR_Target`（＋カカシのレイヤー）、`Block Mask` = 地形・岩、`Ground Mask` = 地形
  - `Pouch`・`Revolver`・`Dust Cloud`・`Lasso`・`Rock Wall`・`Balls`（3 個）・`Relic Pool`（予備の遺物 4 個、全頭同じ並び）・`Haze`（任意）をつなぐ
- **見た目オブジェクト**（乗り物ごとに 1 組。乗り物の子に置いてよい。起動時に親から外れる）
  - `DustCloud`: 半径 1m（`Base Radius`）で作った砂煙（球状のパーティクル）を `Visual`／`Particles` に
  - `LassoEffect`: LineRenderer（縄の色・太さ 3cm 程度）。`Mount Mask` = `HR_Target`
  - `RockWall`: 子に壁 3 枚（各幅 6m・高さ約 4m。`Packs/Cliffs` か `Packs/DesertRocks` の岩＋BoxCollider、レイヤー `HR_Wall`）を `Segments` に。`Ground Mask` = 地形
  - `IronBall` ×3: 直径 0.7m 程度の球（Collider なし）を `Visual` に。`Ground Mask` = 地形（＋`HR_Wall` ではねさせるなら追加）

### 手順
1. 前提：Task 8 と同じ（VRChat SDK 3.8 以降・UdonSharp 1.2 以降）。TextMeshPro の「TMP Essential Resources」を取り込み済み。日本語フォントは同梱の `Assets/HorseRace/Fonts/ipag.ttf`（IPA ゴシック、IPA フォントライセンス v1.0、全文は同じフォルダの `IPA_Font_License.txt`）から Build World が動的 TMP Font Asset（`Assets/HorseRace/Generated/Fonts/JPGothic SDF.asset`）を自動で作り、全部の文字に使う（`Assets/HorseRace/` 以下に別の TMP Font Asset を置けばそちらを優先）

   - UdonSharp のプログラムアセットが無いスクリプトがあると、作ってコンパイルを始め、「もう一度実行してください」と出て止まる。Unity 右下の読み込み表示が止まり Console に U# のコンパイルエラーが無いことを確かめてから、もう一度「HorseRace/Build World」

   - 毛色マテリアル（Create Horse Materials）と Mount.controller（Build Mount Animator）も自動で作り直す
   - レイヤー `Ground`・`Mount`・`Rider`・`Block` が無ければユーザーレイヤー 23〜26（埋まっていれば 22〜31 の空き）に作る。衝突マトリクス：`Rider` は全レイヤーと衝突しない（当たり判定のクエリ専用）、`Mount` は Player / PlayerLocal と衝突しない

### ゲームシステム（system round 2、docs/research/review-log.md）
- [ ] 深い砂（system-r2-01）：砂漠の 500〜900m・1500〜1850m と境目の 300〜520m は道の上も砂（踏み跡が薄い）。入口に風で削れた岩・道を横切る砂の吹きだまり・金の立て札「深い砂」、出口に青緑の「固い地面」。馬は疾走 14.8 m/s、ラクダは 15.5 m/s。それ以外の道の上は砂なし（道の外だけ遅い）。電報・囲いの手配書の壁に「次：砂漠 ― 深い砂 31%・ラクダ有利」「境目 ― 深い砂 9%・馬有利」。ラクダは駆歩 13・疾走 15.5 m/s、疾走の減り 6/秒（馬 12）で、固い地面では馬が約 8% 速い
- [ ] 柵沿いの CP（r2-02）：カーブの外の柵沿い（柵から 2m 以内）を走っても CP の音が鳴る。CP を 1 つ取りこぼしても次の CP で進む（「関門を通り過ぎた」は 2 つ以上先に入ったときだけ）。順位も止まらない
- [ ] やり直し（r2-03）：デスクトップは R、VR はスティック押し込み（または両方のトリガー＋手綱を引く）を 1.2 秒長押しすると首の札に赤い「やり直し… ■■■□□」、最後に通った CP へ戻って 2 秒よろける（Stagger）。デスクトップで R の長押しがアクションメニューと重なって困らないか確かめる。駆歩以上を指示しているのに止まったまま 4 秒（岩に挟まった等）でも自動で戻る。コースの線から 40m（柵の外）に 3 秒いても戻る
- [ ] ひとりで走る（r2-04）：主催者以外が 1 人で台帳にサインすると号砲の札・出走表に「ひとりで走る（タイムアタック）」「出走まで 0:30」、自分の乗り物で待っていれば 0:10。主催者が離席していても出走する。ゴールのタイムはステージのコース記録になり、号砲の札に「第1幕 荒野 記録 3:21.4 名前」。ひとりの時計の途中で 2 人目がサインすると 1:00（全員乗れば 0:15）で決め直す
- [ ] 取り消し（r2-05）：署名済みで選択を変えずに台帳に触れると「取り消す」（右のページに「もう一度触れると取り消す」、触れる前の表示も「台帳：取り消す」）。ロビーとステージの合間に枠が空き、ステージ中の預かりはいつでも消せる。号砲から 20 秒たっても最初の CP に届かず止まっている人は台帳・出走表に「（不在）」、そのステージの点はもらわず次の合間で枠が空く（全員ゴールの判定も待たない）

## 最終チェック（設計レビューの重点項目 1〜5）

計画書（`docs/superpowers/plans/2026-11-27-vrc-horse-race-phase1-v2.md`）の「Review Focus」に対応する。各項目は 2 クライアント以上で確認する。自動テストで計算ロジックは確認済みだが、VRChat 上での実際の挙動はここで初めて分かる。

1. [ ] **マスターがレース中に退出** → 新マスターがそのまま進行を引き継ぐ。レース中に Build & Test の 1 つ目のクライアント（インスタンスのマスター）を閉じ、残ったクライアントでタイマー・順位・ポイントが止まらず続き、ゴール判定・ステージ結果まで進む（時刻はサーバー時刻なので巻き戻らない／二重に進まない）。（上の Task 8 の「マスター退出でも続行」と同じ。ここでは必ず実施）
2. [ ] **コース外落下・地形すり抜け** → 3 秒以内に最後の CP へ戻る。崖下・溝の底・地形の下へ落ちる、コースから 60m 以上離れる、のそれぞれで戻り、戻った直後は速度 0。（Task 7 の確認項目と同じ。近道や岩橋の溝でも試す）
3. [ ] **ステージ途中で参加** → 観戦扱い、次ステージで自動エントリー。レース中に後から入ったクライアントは走れず（中継を見るだけ）。レース中に台帳にサインすると「次のステージから：」に載り、ステージ結果に入ると自動でエントリーされて次のステージから走れる（ステージ結果の間のサインでもよい）。合計は 0 点から。
4. [ ] **同じ遺物を 2 人が同時に取る／3 発目の命中が同時に 2 人から来る** → コースの遺物は一人ずつなので 2 人とも拾える（順位で +0/+1/+2）。落とした遺物（予備）は 1 人だけ確定、遺物は 1 つだけ落ちる。2 人で同時に同じ落とした遺物へ走り込んで Lv が上がるのは 1 人だけ。2 人が同時に 3 発目を当てても、相手の Lv は 1 しか下がらず、落ちる遺物も 1 つ（被弾側で、直前の落下から 1 秒以内の 2 回目は Lv を下げない）。
5. [ ] **速度補正が何重にもかかって止まってしまう** → いちばん強い減速 × 0.85^(ほかの減速の数)、下限 ×0.55 で止まらない。砂地 ＋ リボルバーを外した状態 ＋ 構え ＋ 被弾 ＋ 砂塵 ＋ 投げ縄の相手側 を重ねても ×0.55 程度の速さで進める。よろけ・はじきの後 1.5 秒は守り（鞍の札に金の火花と「守り」）で、続けて当たっても減速は半分の長さ・よろけなし。
